# ☾ The High Magick

Dark, animated website for an occult services brand: spellwork, tarot and pendulum readings.

## Run
Open `index.html` in a browser, or host free with **GitHub Pages**: push these files, then Settings → Pages → deploy from `main` / root.

## Edit before publishing
- `index.html`: replace `91XXXXXXXXXX` (WhatsApp number with country code) and `yourhandle` (Instagram).
- Spell prices (all above ₹666) and reading prices are in the `#spells` and `#readings` sections.
- Add real photos to an `assets/` folder and reference them with `<img>` tags if you want.

## Features
Starfield canvas, cursor glow, rotating sigil, floating moon, swinging pendulum, scroll reveals, accordion education section and a flip-card tarot draw. Honest "not guaranteed" disclaimers are included throughout.
